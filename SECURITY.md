# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| v0.1.0  | :white_check_mark: |

## Reporting a Vulnerability

The DSO183 custom firmware is a small, community-maintained embedded project for
a single-channel oscilloscope. There is no dedicated security team and no
security advisory mailing list.

If you discover a security concern, please report it by opening a public issue
on the repository, or by contacting the maintainer directly through the GitHub
issue tracker. Include:

- A clear description of the issue
- Steps to reproduce (if applicable)
- The affected firmware version or commit
- Whether the issue requires physical access to the instrument

We will acknowledge receipt within a reasonable time and work with you to
understand and address the issue. Because this is a volunteer project with no
formal security program, we cannot guarantee a specific response timeline or
the issuance of CVEs.

## Scope

This policy covers the firmware source code in this repository. It does not
cover the JYE Tech DSO183 stock firmware, the vendor binary (not part of this
repository), or third-party components (STM32 HAL, CMSIS, Adafruit GFX font),
each of which is governed by its own copyright and license.
